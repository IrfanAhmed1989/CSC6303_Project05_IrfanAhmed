# Project 05 – Python Folder & File Creation Program
**Author:** Ahmed, Irfan  
**OS:** macOS (Apple Silicon)

This program:
- Prompts the user for a folder name  
- Automatically appends a timestamp  
- Removes the folder if it already exists  
- Creates a new folder  
- Generates 100 random integers (0–1000)  
- Saves them into `numbers100.txt`  
- Includes full verification of line count, integer validity, range, and trailing newline  

This was submitted as Project #5 for CSC6303.
